# control

Cross-project requirements & decision catalog. See `CONTROLLER.yaml`.

This is not a product — it's a fast index so a new Claude session or sub-agent (in this repo, or in `compliance-tracker`/`projexa`/`veda-advisors`) doesn't have to re-derive context from scratch. It never duplicates content that lives elsewhere (a PR, an artifact, a project's own tracker) — every entry points, it doesn't restate.

Read `CONTROLLER.yaml`'s own header for the full protocol.
